Política de Privacidad

Última actualización: 15 de septiembre de 2026

1. Alcance

Esta Política explica cómo n8n Yo Amo La Historia trata la información necesaria para conectar cuentas autorizadas y ejecutar acciones de publicación solicitadas por el usuario.

2. Datos que podemos procesar

  • Identificadores básicos de cuenta y canal proporcionados por las plataformas conectadas.
  • Tokens de acceso u otras credenciales técnicas necesarias para realizar solicitudes autorizadas a las APIs.
  • Archivos multimedia que el usuario selecciona para publicar, como videos o imágenes.
  • Títulos, descripciones, etiquetas, hashtags, identificadores de playlists y otros metadatos de publicación.
  • Información técnica mínima necesaria para diagnosticar errores de ejecución.

3. Finalidades

Los datos se utilizan exclusivamente para autenticar al usuario, ejecutar publicaciones solicitadas, administrar el flujo de trabajo, detectar errores y mantener la seguridad del servicio.

4. Venta y publicidad

No vendemos datos personales. Tampoco utilizamos datos obtenidos desde APIs de terceros para publicidad personalizada.

5. Compartición con terceros

Los datos pueden transmitirse a las plataformas que el usuario haya conectado y a proveedores técnicos necesarios para ejecutar el flujo, como servicios de automatización, almacenamiento o infraestructura. Solo se comparte la información necesaria para prestar la función solicitada.

6. Retención

Los datos se conservan únicamente durante el tiempo necesario para ejecutar el servicio, cumplir obligaciones legales o mantener la configuración autorizada por el usuario. Los archivos multimedia pueden ser procesados temporalmente y luego movidos, sustituidos o eliminados conforme a la configuración del flujo de trabajo.

7. Seguridad

Aplicamos medidas razonables para reducir el riesgo de acceso no autorizado, pérdida o uso indebido. Ningún sistema puede garantizar seguridad absoluta.

8. Revocación de acceso

El usuario puede revocar permisos desde la configuración de la plataforma conectada. La revocación puede impedir nuevas publicaciones automáticas.

9. Eliminación de datos

El usuario puede solicitar la eliminación de los datos asociados escribiendo a gara1889.cetis70@gmail.com. La solicitud debe identificar razonablemente la cuenta o integración correspondiente. Cuando sea aplicable, eliminaremos o desvincularemos los datos controlados por este servicio, salvo que exista una obligación legal de conservarlos.

10. Menores

El servicio no está dirigido específicamente a menores de 13 años y no pretende recopilar conscientemente información personal de menores.

11. Sitio web

Este sitio informativo estático no utiliza analítica ni publicidad por defecto. Los servicios externos enlazados pueden aplicar sus propias tecnologías y políticas.

12. Cambios a esta política

Podemos actualizar esta política cuando cambien las funciones, las integraciones o los requisitos legales. La fecha de actualización aparecerá en esta página.
